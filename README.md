# Budget Flow Planner

Красивый одностраничный планировщик бюджетов с календарем, историей коммитов плана и подготовленным слоем синхронизации через Google Apps Script.

## Что уже есть

- экран планирования без сборки и зависимостей
- редактор плана с категориями, бюджетом, резервом и контрольными датами
- календарь ревью и коммитов
- история фиксаций плана
- локальное хранение в `localStorage`
- шаблон backend-а для Google Drive через Apps Script
- базовый слой авторизации через доступ к Apps Script и дополнительный `SYNC_TOKEN`

## Быстрый старт

Открой `index.html` в браузере.

Для надежной синхронизации с Apps Script удобнее открывать страницу не по `file://`, а через любой простой статический хостинг или локальный сервер.

Текущий `Apps Script Web App` уже предустановлен в интерфейсе по умолчанию.

## Структура

- `index.html` - интерфейс
- `assets/styles.css` - стили и анимации
- `assets/app.js` - логика планировщика
- `apps-script/Code.gs` - backend для Google Apps Script
- `apps-script/README.md` - как подключить Google Drive
