# Mobile

Expo-версия приложения `Планирование семьи`.

## Что внутри

- общий Supabase backend и те же таблицы, что использует веб-версия
- мобильная навигация по разделам:
  - Календарь
  - События
  - Планы
  - Лента
  - Настройки
- локальное хранение темы, сессии и последнего раздела через `AsyncStorage`

## Старт

```bash
cd mobile
npm install
npm run start
```

## Сборка

```bash
npm run android
npm run ios
```

## Важно

Мобильная версия использует ту же схему Supabase, что и веб-приложение. Перед первым запуском убедитесь, что SQL из `supabase/relational_state.sql` уже применен.
